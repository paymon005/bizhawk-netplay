# BizHawk Netplay

A C# external tool (ApiHawk) that adds online multiplayer to any local-multiplayer game BizHawk can run, using delayed lockstep as the universal baseline, with GGPO-style rollback as a drop-in strategy for cores that can afford it.

See [bizhawk-netplay-architecture.md](bizhawk-netplay-architecture.md) for the full design.
